# 排版规范

## 公众号
- 正文 15px，行高 1.8，字间距 1px，颜色 #3f3f3f；注释 12px #888；小标题 18px 加粗。
- 两侧留白 12px，不首行缩进，段落控制在 3–4 行内；全文不超过三种颜色（墨黑、正文灰、朱红）。
- 中英文、数字之间加半角空格（脚本自动处理）。
- 头条封面 900×383（2.35:1），文字放在上方 60%，下方会被信息流标题条遮住；次条封面 500×500。

## 小红书
- 3:4，1080×1440，整套同一模板（封面、每条头条一张、专题、编辑手记，通常 8 张）、同一配色，保持系列感。
- 封面只放大标题：最多 3 行、每行不超过 8 个字，再加一行副标题；重要信息不放在底部 15%。
- 四周留白 80px（约 7%）；内页正文不小于 32px；最多两种字体（思源宋体标题 + 思源黑体正文）。
- 行首不出现标点、末行不留孤字（脚本自动处理）。

## 公众号外链
- 普通订阅号正文不能放外部链接（只有认证且开通微信支付的账号可以）。所以 wechat/wechat.html 不放外链：热榜每条带角标，文末列出原文地址，发布时把「原文链接」设为当期网页版 https://emotionalronan.github.io/ai-daily-report/reports/DATE/，读者点「阅读原文」即可一键打开每条原文。
- wechat/wechat_links.html 是标题可直接点击的版本，账号有外链权限时用它。
- 网页版由 gh-pages 分支发布，每期推送时同步：`git push origin main:gh-pages`。

## 配图
- 每条头条配一张图，只用该新闻原文页面上的图（og:image 或正文图），由 scripts/fetch_images.py 下载到 reports/DATE/wechat/img/h1.jpg…，图下注明「图片来源：出处」。
- 选能说明事件的图：图表、产品图、现场照片、发布页主视觉；纯色/模糊背景、只有 logo 的图尽量换掉（候选在 work/DATE/img_candidates.json，用 "image_url" 指定）。实在没有就写 "image_skip"。
- 网页版在标题下展示；公众号版用网页版上的图片地址，粘贴到编辑器时随之转存；小红书每条头条一张卡，图在上方裁成 16:9。
- 不用生成的插图冒充新闻图。
