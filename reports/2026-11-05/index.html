头条 一

OpenAI：一次运行，在 Linux 内核里做出 948 个提权利用

OpenAI 周三公布，其自动化流水线在 Linux 内核里筛出 2308 个候选问题，复现 1724 个，做出 948 个可让普通用户拿到 root 的利用，API 花费约 121 万美元。据报道已有 61 个在上游修复。

OpenAI 称 7 月同类测试只有 166 个，三个月内核已加固，数字反而涨了五倍多。以上均为 OpenAI 自报，细节取自其博文与媒体转述。

来源：OpenAI
头条 二

PHP2Shell：一个被当成“只会崩溃”的旧 bug，成了远程执行漏洞

IEEE Spectrum 称，PHP2Shell 的底层内存错误 2024 年就报给了 PHP 基金会，因只导致崩溃而搁置；今年安全公司 Calif 借 AI 工具两周内做出代码执行，四位工程师又花了两个月才出补丁。

文中专家称“找 bug 和修 bug 并不对称”。约翰斯·霍普金斯的马修·格林预计，要等真出大事才有人买单，这是他的判断。

来源：IEEE Spectrum
头条 三

Kimi K3.1 Pro 开放权重：2.8T 参数，评测含网络安全

月之暗面在 Hugging Face 放出 Kimi K3.1 Pro 权重：混合专家架构，总参数 2.8T、激活 104B，上下文 100 万 token。模型卡自报 ExploitBench 74.7，表中 GPT-6 Astra 为 100，Claude Opus 5.5 为 91。

数字全是厂商自报，且许可证对高收入使用方有付费门槛，HN 评论里有人提到。但开放权重模型开始摆出攻击类评测，这是新信号。

来源：Hugging Face
