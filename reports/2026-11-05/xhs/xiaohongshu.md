# AI 找漏洞，比人修得快

OpenAI 称一次运行在 Linux 内核做出 948 个提权利用；PHP2Shell 的旧 bug 被 AI 辅助变成代码执行漏洞；Kimi K3.1 Pro 开放 2.8T 权重，评测含攻击类。

📌 今天最重要的三件事

1. OpenAI：一次运行，在 Linux 内核里做出 948 个提权利用
OpenAI 称 7 月同类测试只有 166 个，三个月内核已加固，数字反而涨了五倍多。以上均为 OpenAI 自报，细节取自其博文与媒体转述。

2. PHP2Shell：一个被当成“只会崩溃”的旧 bug，成了远程执行漏洞
文中专家称“找 bug 和修 bug 并不对称”。约翰斯·霍普金斯的马修·格林预计，要等真出大事才有人买单，这是他的判断。

3. Kimi K3.1 Pro 开放权重：2.8T 参数，评测含网络安全
数字全是厂商自报，且许可证对高收入使用方有付费门槛，HN 评论里有人提到。但开放权重模型开始摆出攻击类评测，这是新信号。
